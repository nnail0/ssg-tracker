# SSG Tracker
A Python-based flight tracking software project for use with the University of New Mexico's Small Satellite Group. 
Developing v0.1 alpha in Python using GTK6 (with fallbacks if we run into a time crunch)

This README and code architecture are very new and are still a work in progress. 

## Setup
Necessary software:
- UV (Python environment manager, install beforehand)
- A code editor or IDE (Visual Studio Code \[free\], PyCharm \[free with school email\], etc.)

For the ability to modify this code, please do the following:
- Provide me with your email for repo access (check email address below)
- Create a local fork of the repository
- Run `uv sync` in the terminal in the repo directory to ensure you have the libraries you need.

## Testing and Running
- While developing, run and test incrementally using `uv run` on a file or files.
- Reference the UV documentation or the internet for other features or uses.
